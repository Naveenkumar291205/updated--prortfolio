## 💻 Run Locally

```bash
# Clone the repository
git clone https://github.com/Naveenkumar291205/updated--prortfolio.git

# Navigate into project directory
cd updated--prortfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```
